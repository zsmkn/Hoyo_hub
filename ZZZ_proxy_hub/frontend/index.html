絕區零 自動簽到

伺服器開著時，每天 00:10（台灣時間）自動幫你在 HoYoLAB 簽到；那時電腦沒開的話，下次啟動會自動補簽。
同一個 HoYoLAB 帳號的 Cookie 三款遊戲共用，每款遊戲可以分別開關。

如何取得 HoYoLAB Cookie？
  1. 用電腦瀏覽器登入 hoyolab.com
  2. 按 F12 → Application（應用程式）→ Cookies → https://www.hoyolab.com
  3. 找到 ltoken_v2、ltuid_v2（以及 ltmid_v2），照格式貼上：
    ltoken_v2=v2_xxx; ltuid_v2=12345678; ltmid_v2=xxx

⚠ Cookie 等同於登入憑證，只會用來簽到，系統只保留簽到需要的欄位且不會回傳給前端。請勿在不信任的網站貼上。

Discord Bot API（給 Bot 開發者）

所有請求需帶 Header X-Bot-Key（第一次啟動時產生，存放在 data/secrets.json）。路徑中的 {game} 是 zzz、gi 或 hsr；省略時預設為絕區零。Cog 模組在 discord_cog/。
